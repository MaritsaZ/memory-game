# Memory Game

Memory Game is a card matching game built with HTML, CSS, and JavaScript.

The game contains 16 cards forming 8 matching pairs. The goal is to find all matching pairs using as few moves as possible.

## Features

- 16 cards with 8 matching pairs
- Random card shuffling
- Move counter
- Matched pairs counter
- New Game functionality

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/MaritsaZ/memory-game.git
```

2. Open the project folder:

```bash
cd memory-game
```

3. Switch to the `memory-game` branch:

```bash
git switch memory-game
```

4. Open `index.html` in your browser.

No additional dependencies or installation are required.
